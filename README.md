# Paymos for CS-Cart

CS-Cart payment processor add-on for Paymos hosted checkout.

The package is generated by Paymos dashboard with API keys and webhook secrets already injected into:

```
app/addons/paymos/paymos-config.php
```

Upload the ZIP contents to the CS-Cart root, install the Paymos add-on, then create a payment method that uses the **Paymos** processor.

## Requirements

- CS-Cart or Multi-Vendor 4.20+
- PHP version supported by your CS-Cart install
- Public HTTPS storefront URL
- Active Paymos project

No Composer install is required on the CS-Cart server. The generated package ships with the Paymos PHP SDK bundled.

## Webhook

The dashboard registers this callback path when the package is generated:

```
/index.php?dispatch=payment_notification.notify&payment=paymos&mode=webhook
```

The processor accepts only `mode=webhook` for Paymos server notifications.
